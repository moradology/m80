# systemd Packaging Notes

m80 VM launches use transient `systemd-run` units generated by
`m80-firecracker`; there is intentionally no installed `m80-vm@.service`
template. A static template would still need per-VM `--property=` overrides for
resource limits, logs, and namespace choices, so it would split the launch
contract across two files without reducing runtime complexity.

This directory is reserved for operator-facing systemd examples that manage an
m80 consumer process. Those examples are not required for VM launch.
