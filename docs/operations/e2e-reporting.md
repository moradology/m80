# Privileged E2E Reporting

`scripts/run-e2e.sh --json` emits the machine-readable contract for the
privileged real-KVM battery. Operators use it to distinguish runnable tests,
skips caused by host prerequisites, and real failures without scraping libtest
text output.

Validate any report before consuming it:

```sh
scripts/run-e2e.sh --list --json > /tank/tmp/m80-e2e-report.json
python3 scripts/validate-e2e-report.py /tank/tmp/m80-e2e-report.json
```

## Schema

Current reports use `schema_version: 1`. Unknown fields are invalid; a future
shape must bump `schema_version`.

Top-level fields:

| Field | Type | Meaning |
| --- | --- | --- |
| `schema_version` | integer | Must be `1`. |
| `generated_at` | string | UTC RFC3339 timestamp ending in `Z`. |
| `package` | string | Cargo package whose integration tests were selected. |
| `run_root` | string | Run root passed to tests as `M80_RUN_ROOT`. |
| `list_only` | boolean | `true` when generated by `--list`. |
| `timeout_seconds` | integer | Per-test timeout used for real execution. |
| `environment` | object | Detected host features and opt-ins. |
| `artifacts` | object | Kernel, rootfs, and jailer-harden paths used by the run. |
| `summary` | object | Counts derived from `results`. |
| `results` | array | Per-test pass, fail, skip, or list records. |
| `exit_code` | integer | Wrapper exit code: `0` when no failures were recorded. |

`environment` fields are booleans:

| Field | Meaning |
| --- | --- |
| `sudo_available` | The wrapper can use root or passwordless `sudo -n`. |
| `kvm_available` | `/dev/kvm` is readable and writable. |
| `artifacts_available` | The default kernel/rootfs artifact paths exist. |
| `jailer_harden_available` | `m80-jailer-harden` exists and is executable. |
| `iproute2_available` | `ip` is on `PATH`. |
| `cgroup_v2_available` | Unified cgroup v2 is mounted. |
| `loop_device_available` | A loop-control or loop device is visible. |
| `debugfs_available` | `debugfs` is on `PATH`. |
| `docker_available` | Docker is installed and the daemon is reachable. |
| `measurement_enabled` | `M80_RUN_MEASUREMENT_E2E=1`. |
| `pmem_artifacts_available` | A pmem/erofs fixture variable is set. |
| `external_network_enabled` | `M80_RUN_EXTERNAL_NETWORK_E2E=1`. |
| `malicious_artifacts_available` | `M80_MALICIOUS_ARTIFACT_DIR` exists. |
| `minimal_artifacts_available` | Minimal image-kind artifacts and schema-5 manifest exist. |
| `ubuntu_artifacts_available` | Ubuntu image-kind artifacts and schema-5 manifest exist. |

`artifacts` fields are strings:

| Field | Meaning |
| --- | --- |
| `kernel` | `M80_KERNEL_IMAGE` path or the wrapper default. |
| `rootfs` | `M80_ROOTFS_IMAGE` path or the wrapper default. |
| `jailer_harden` | `M80_JAILER_HARDEN_BIN` path or the wrapper default. |

`summary` fields are non-negative integers and must match `results` exactly:

| Field | Meaning |
| --- | --- |
| `passed` | Count of `status: "pass"`. |
| `failed` | Count of `status: "fail"`. |
| `skipped` | Count of `status: "skip"`. |
| `listed` | Count of `status: "list"`. |
| `total` | Total number of result records. |

Each `results[]` entry has:

| Field | Type | Meaning |
| --- | --- | --- |
| `status` | string | One of `pass`, `fail`, `skip`, or `list`. |
| `test` | string | libtest test name. |
| `binary` | string | Test executable basename. |
| `reason` | string or null | Required for `skip`; optional for `fail`; null otherwise. |
| `exit_code` | integer | Per-test command exit code. |
| `duration_ms` | integer | Per-test runtime, or `0` for list/skip records. |
| `stdout_excerpt` | string | Present only on `fail`; last 4000 bytes of stdout. |
| `stderr_excerpt` | string | Present only on `fail`; last 4000 bytes of stderr. |

## Interpretation

- `skip` means the taxonomy admitted the ignored test but the current host lacks
  a required feature or opt-in. The `reason` names the first missing gate.
- `list` means the test is runnable in this environment but was not executed
  because `--list` was used.
- `fail` means libtest or the wrapper command failed. `reason: "timeout"` is
  reserved for the wrapper timeout; other failures keep `reason: null` and put
  diagnostics in the excerpts.
- `pass` means the exact ignored test exited `0`.

The report does not replace preserved run directories. For real failures, use
the excerpts to find the test, then inspect `failure_summary.json`,
`diagnostics.jsonl`, and `console.log` under the run root as described in
[`e2e-local-dev.md`](e2e-local-dev.md).
